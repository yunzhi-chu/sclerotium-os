```
设计理念:

class MyceliumBioInterface:
    """
    菌丝体生物电信号接口
    
    隐喻: 菌根外围菌丝 — 探入土壤感知水分/养分/毒素

    - 3M+ chips per growth cycle, fully biodegradable
    - 替代方案: FPGA模拟菌丝体电动力学
```

#### 3.2.2 SNNSpikingEncoder (`src/l1/snn_spiking_encoder.py`)

```
设计理念:
脉冲神经网络(SNN)以脉冲时间编码信息——最接近生物大脑的计算范式。
2026年多核SNN芯片实现1.05 TFLOPS/W能效(28nm)，首次支持片上训练。

核心类:
class SNNSpikingEncoder:
    """
    脉冲神经网络编码器
    
    隐喻: 视网膜神经节细胞 — 光强度→脉冲频率编码
    论文: SOLO (Spatial Online Learning at Once) — 仅用最后时间步梯度
    """
    
    - encode(signal: np.ndarray, method: str = "rate") → SpikeTrain
      编码方式:
      - rate: 信号强度→脉冲频率 (泊松过程)
```
